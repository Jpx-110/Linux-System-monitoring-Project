# Linux-System-monitoring-Project
In this project, I will create a Linux system monitor using a shell script. The system monitor will continuously monitor the CPU, memory, and disk usage of your Linux system and display the usage percentages. If any of the thresholds for CPU, memory, or disk usage are exceeded, an alert will be sent. 


# Linux System Monitor

## Project Overview
This project involves building a lightweight Bash script to monitor system resources in real-time. It was created to demonstrate proficiency in Linux command-line tools, text processing with `awk`, and Bash scripting automation.

## Features
- **CPU Monitoring**: Tracks load averages using `uptime`.
- **Memory Tracking**: Parses `free` command output to show real-time RAM usage.
- **Disk Usage**: Monitors the root filesystem capacity using `df`.

## Prerequisites
- A Linux environment (Ubuntu/Debian/CentOS)
- Bash shell
